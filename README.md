## 🥐 About The Project

A high-fidelity demo website for **Preacher's Patisserie**, a cherished Scottish bakery and café located in Edinburgh. Designed as a digital showcase celebrating their authentic Scottish baking craft, freshly prepared morning rolls, delicious lunchtime wraps, artisan coffee, and heritage since 1958.

### Key Features
- **3-Page Clean Experience**:
  1. **Home**: Hero showcase, compact business strip, marquee ticker, *"Made with a little history"* story, featured signature counter bakes, 3-category menu preview, and Google reviews (4.8 ★ with 330+ reviews).
  2. **Menu**: Digital bakery menu layout with category filters (*Savoury & Morning Rolls*, *Sweet & Home Baking*, *Coffee & Hot Drinks*) with real product photography.
  3. **Contact & Location**: 7-day opening hours schedule, directions, interactive location map, phone links, and Instagram/Facebook channels.
- **Brand Visual Identity**: Powder blue, soft sage green, warm cream backgrounds, dark ink text, and subtle coral accents.
- **100% Real Bakery Photography**: Uses real Preacher's Patisserie photography.
- **Fully Responsive & Accessible**: Mobile-friendly navigation with responsive drawer and tap targets.

## 🛠 Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Playfair Display, Cormorant Garamond, Plus Jakarta Sans

### 1. Install Dependencies

### 2. Run Development Server

### 3. Build for Production
